# AI Financial Advisor Frontend

## Project Overview

This is the web frontend for the AI Financial Advisor application, providing a modern chat-based interface for interacting with the multi-agent financial advisory system.

## Technologies Used

This project is built with:

- **Vite** - Fast build tool and development server
- **TypeScript** - Type-safe JavaScript
- **React** - UI framework
- **shadcn-ui** - Component library
- **Tailwind CSS** - Utility-first CSS framework

## Development Setup

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Getting Started

```sh
# Step 1: Navigate to the frontend directory
cd frontend

# Step 2: Install the necessary dependencies
npm install

# Step 3: Start the development server with auto-reloading
npm run dev
```

The application will be available at `http://localhost:8080`

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build for production
- `npm run build:dev` - Build for development
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build

## Project Structure

- `/src/components` - React components
- `/src/pages` - Page components
- `/src/stores` - Zustand state management
- `/src/types` - TypeScript type definitions
- `/src/lib` - Utility functions
- `/public` - Static assets
